# Keyboard shortcuts

Every command below is in the menu bar too, so Help › Search finds it and System Settings ›
Keyboard › Keyboard Shortcuts can give it a shortcut of your own. [The window](how-it-works.md#the-window)
describes the menus.

## Anywhere in the window

| Keys | What it does | Menu |
|---|---|---|
| ⌘N | New recording, or back to the call being recorded | Recording › New Recording |
| ⇧⌘R | Stop recording (asks first) | Recording › Stop Recording… |
| ⇧⌘N | New folder | File › New Folder |
| ⌘R | Refresh calendars | File › Refresh Calendars |
| ⌥⌘F | Search every meeting | Edit › Search Meetings |
| ⌘L | Ask about your meetings, on Home or in a meeting | Edit › Ask About Your Meetings |
| ⌘[ and ⌘] | Back and Forward, after following a to-do's link, a citation in Ask, a search result or a link in a summary | Go › Back, Go › Forward |
| ⌘+, ⌘- and ⌘0 | Bigger text, smaller text and actual size | View |
| ⌃⌘S | Hide or show the sidebar | View › Hide Sidebar |
| ⌘Z | Put back what was just moved to the Trash | Edit › Undo |
| ⌘, | Settings | Oatcake › Settings… |

The sidebar’s recording button shows ⌘N. The Oatcake status menu in the macOS menu bar shows
⌘N for New Recording and ⌘, for Settings. Neither is a system-wide shortcut.

Go › Home, To-dos and All Meetings, Recording › Join Call and Show Live Notes, and Help › Oatcake
Help (these pages) have no keys of their own.

## In a meeting

| Keys | What it does | Menu |
|---|---|---|
| ⌘1, ⌘2, ⌘3, ⌘4 | Summary, Transcript, My notes, and Draft in a meeting with a draft for sharing | View |
| ⌘F | Find on the tab showing: its words are marked | Edit › Find… |
| ⌘G and ⇧⌘G | The next and previous line with the words, on the Transcript tab | Edit › Find Next, Find Previous |
| Escape | Close Find, or Ask's conversation, wherever the keyboard is | |
| Space | Play or pause the recording, when no text field has the keyboard | |
| ⌥← and ⌥→ | Back and on 15 seconds in the recording, when no text field has the keyboard | |

Everything else that can be done to the meeting is in the Meeting menu, which has the same
commands as the meeting's **⋯** menu and its right-click menu, including **Rename…**, **Move To**
and **Move to Trash**.

## The meeting list and the sidebar

| Keys | What it does | Menu |
|---|---|---|
| ↑ and ↓ | The meeting, or folder, before or after | |
| ⌘⌫ | Move the meetings selected in the list to the Trash, and open the next one, as in Mail; in the sidebar, the folder or meeting selected (a folder with meetings in it asks first) | File › Move to Trash |
| → and ← | Show or hide a folder's folders; ← on a closed folder goes up to the folder it's in | |
| Return | Rename the folder or meeting selected in the sidebar | |

## Search

| Keys | What it does |
|---|---|
| ↑ and ↓ | Choose a result |
| Return | Open it, on the tab where the words are |
| Escape | Close search |

Search keeps its words and results when you open one: ⌥⌘F and ↓ go on to the next.

## New recording and Who's who

| Keys | What it does |
|---|---|
| Return | Start recording (in the prep notes, it adds the point typed instead) |
| Escape | Cancel, back to where you were before |
| ⌘S | Save in Who's who, or Update meeting for one saved without checking |
